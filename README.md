# ODIN Command Center

A local-first command center built with React and Vite. Tasks are stored in this browser, and CSV analysis runs locally without uploading files.

See the [Usage Guide](USAGE.md) for supported commands, task management, CSV requirements, and browser limitations.

## Run locally

```sh
npm install
npm run dev
```

## GitHub Pages

Push to `main` to build and deploy the app with GitHub Actions. The app is configured for the `/OdinAI/` repository path.
